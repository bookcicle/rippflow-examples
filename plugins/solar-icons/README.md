# Solar Bold Duotone Studio Icons (`solar-icons`)

Bubbly, rounded **Solar Bold Duotone** icon pack plugin for Rippflow Studio, sourced from [480 Design's Solar Icon Set](https://github.com/480-Design/Solar-Icon-Set) via `@iconify-json/solar`.

## Install & Activate

```bash
rippflow plugin add plugins/solar-icons/solar-icons.yaml
```

Then activate in Rippflow Studio via **Settings → Appearance & Theme → Icon Pack → Solar Bold Duotone (Bubbly)**.
