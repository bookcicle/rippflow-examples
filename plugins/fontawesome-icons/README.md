# Font Awesome Free Studio Icons (`fontawesome-icons`)

Open-source **Font Awesome Free 6.x** icon pack plugin for Rippflow Studio, sourced from [`FortAwesome/Font-Awesome`](https://github.com/FortAwesome/Font-Awesome).

## License

Font Awesome Free is licensed under **CC BY 4.0** (icons) and **MIT** (code) — see [`LICENSE.txt`](./LICENSE.txt) in this directory.

## Install & Activate

```bash
rippflow plugin add plugins/fontawesome-icons/fontawesome-icons.yaml
```

Then activate in Rippflow Studio via **Settings → Appearance & Theme → Icon Pack → Font Awesome Free (OSS)** or **Settings → Plugins & Extensions → Use Icons**.
