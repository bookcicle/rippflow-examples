# Material Design Studio Icons (`material-icons`)

Official open-source **Google Material Design** icon pack plugin for Rippflow Studio, sourced from [`google/material-design-icons`](https://github.com/google/material-design-icons) via [`@material-design-icons/svg`](https://github.com/marella/material-design-icons/tree/main/svg).

## License

All SVG icons in `icons/` are licensed under the **Apache License, Version 2.0** — see [`LICENSE`](./LICENSE) in this directory.

## Install & Activate

```bash
rippflow plugin add plugins/material-icons/material-icons.yaml
```

Then activate in Rippflow Studio via **Settings → Appearance & Theme → Icon Pack → Material Design Icons (OSS)** or **Settings → Plugins & Extensions → Use Icons**.
