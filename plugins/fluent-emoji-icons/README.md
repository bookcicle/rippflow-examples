# Fluent Emoji Flat Studio Icons (`fluent-emoji-icons`)

Playful, bubbly, full-color **Microsoft Fluent Emoji Flat** icon pack plugin for Rippflow Studio (`multicolor: true`), sourced from [`microsoft/fluentui-emoji`](https://github.com/microsoft/fluentui-emoji) via `@iconify-json/fluent-emoji-flat`.

## Install & Activate

```bash
rippflow plugin add plugins/fluent-emoji-icons/fluent-emoji-icons.yaml
```

Then activate in Rippflow Studio via **Settings → Appearance & Theme → Icon Pack → Fluent Emoji Flat (Color)**.
