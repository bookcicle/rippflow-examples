# Lucide Studio Icons (`lucide-icons`)

Open-source **Lucide** icon pack plugin for Rippflow Studio, sourced directly from [`lucide-icons/lucide`](https://github.com/lucide-icons/lucide).

## License

All SVG icons in `icons/` are licensed under the **ISC License** — see [`LICENSE`](./LICENSE) in this directory.

## Install & Activate

```bash
rippflow plugin add plugins/lucide-icons/lucide-icons.yaml
```

Then activate in Rippflow Studio via **Settings → Appearance & Theme → Icon Pack → Lucide Icons (OSS)** or **Settings → Plugins & Extensions → Use Icons**.
