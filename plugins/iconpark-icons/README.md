# IconPark Multi-Color Studio Icons (`iconpark-icons`)

Vibrant, chunky, multi-color **ByteDance IconPark** icon pack plugin for Rippflow Studio (`multicolor: true`), sourced from [`bytedance/IconPark`](https://github.com/bytedance/IconPark) via `@iconify-json/icon-park`.

## Install & Activate

```bash
rippflow plugin add plugins/iconpark-icons/iconpark-icons.yaml
```

Then activate in Rippflow Studio via **Settings → Appearance & Theme → Icon Pack → IconPark Multi-Color (OSS)**.
